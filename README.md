# API-пайплайн для анализа отзывов

## О проекте
Программа анализирует отзывы покупателей с помощью языковой модели Qwen 2.5 3B. Она определяет тональность, выделяет основную тему и присваивает категорию каждому отзыву.

## Данные
Входной файл `input.csv` содержит:
- `id` — номер отзыва
- `text` — содержание отзыва

## Подготовка и запуск
1. Установите необходимые библиотеки:
   `pip install -r requirements.txt`
2. Создайте файл `.env` со следующими настройками:
   ```txt
   API_KEY=ollama
   BASE_URL=http://localhost:11434/v1
   MODEL_NAME=qwen2.5:3b
   ```
3. Убедитесь, что Ollama установлена, запущена и модель `qwen2.5:3b` загружена.
4. При желании измените отзывы в `input.csv`.
5. Выполните команду `python run.py`.

## Выходные данные
После выполнения программы результаты анализа появятся в файле `output.json`. В нём для каждого отзыва сохраняются исходный текст, тональность, тема и категория. При повторном запуске файл обновляется.

### Пример входных данных (`input.csv`)

```csv
id,text
1,"Наушники подключаются быстро, звук отличный."
```

### Пример выходных данных (`output.json`)

```json
[
  {
    "id": "1",
    "text": "Наушники подключаются быстро, звук отличный.",
    "sentiment": "positive",
    "topic": "качество звука",
    "product_aspect": "товар"
  }
]
```
